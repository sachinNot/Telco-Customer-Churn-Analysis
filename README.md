# 📊 Telco Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn in a telecommunications company using Excel, MySQL, and Power BI.

The objective is to identify why customers leave and provide business recommendations to reduce churn.

## 🛠️ Tools & Technologies

* Microsoft Excel
* MySQL
* MySQL Workbench
* Power BI
* SQL

## 📂 Project Files

* `Customer_Churn_Analysis.xlsx` – Excel analysis and summary.
* `Telco_Customer_Churn_Analysis.sql` – SQL queries and analysis.
* `customers churn.pbix` – Interactive Power BI dashboard.
* `WA_Fn-UseC_-Telco-Customer-Churn.csv` – Original dataset.

## 📈 Key Metrics

| Metric                  |       Result |
| ----------------------- | -----------: |
| Total Customers         |        7,043 |
| Churned Customers       |        1,869 |
| Retained Customers      |        5,174 |
| Churn Rate              |       26.54% |
| Average Tenure          | 32.37 months |
| Average Monthly Charges |        64.76 |

## 🔍 Key Insights

1. Month-to-month contract customers have the highest churn.
2. Electronic check users show the highest churn.
3. Fiber optic customers contribute significantly to churn.
4. Customers with shorter tenure are more likely to leave.
5. Churned customers have higher average monthly charges.

## 💡 Business Recommendations

* Encourage long-term contracts through discounts.
* Promote automatic payment methods.
* Improve Fiber Optic service quality.
* Offer special deals to new customers.
* Contact high-risk customers proactively.
